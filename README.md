## ▶️ How to Run

1. Install [Python 3](https://www.python.org/downloads/).
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run any program, for example:

```bash
python 02_age_calculator.py
```

Enter the requested values when prompted. Each script runs independently.

## 📚 Concepts Practiced

- Variables and input/output
- Strings, integers and floating-point numbers
- Arithmetic operations
- Basic formatting
- Simple conditionals and input checks

## 📝 Notes

These programs are learning exercises, not production-grade financial or medical tools. The recharge calculator uses a GST percentage entered by the user; it does not determine applicable tax rules. The BMI calculator is a basic numerical exercise.
